## Règle d’or (avant tout prompt)

**Contemplation puis action · une preuve vérifiable à la fois.**

Colle ceci en tête de conversation si l’IA invente des chiffres :

```text
Tu travailles pour CirculAI (pilote territorial Québec) et Egor69 (culture / encyclopédie).
INTERDIT : inventer partenariats RECYC-Québec, IQ, chiffres de pilote, ou promesses scientifiques.
OBLIGATOIRE : ton humble, français québécois, distinguer CirculAI (mairie) vs Egor69 (public).
Si une donnée manque, dis « baseline honnête — pilote non démarré ».
```

## 1. Méta-prompt — écouter d’abord (Blog du Modérateur)

*Pose les questions avant de produire.*

```text
J’ai besoin d’aide pour [OBJECTIF EN UNE PHRASE].
Avant de rédiger quoi que ce soit, pose-moi toutes les questions utiles :
public (maire / OBNL / citoyen / investisseur), contraintes, format, longueur, ce qu’il ne faut PAS dire.
Ne produis aucun contenu tant que je n’ai pas répondu.
Organise tes questions : essentiel d’abord, puis détails.
```

**Usage Dominic :** avant une lettre mairie, un post Facebook, ou une planche encyclopédie.

## 2. Challenger intellectuel — ne pas se faire flatter (BDM)

```text
Ne m’approuve pas par réflexe. Sois un partenaire exigeant :
- Quelles suppositions sont fragiles ?
- Qu’est-ce qu’un sceptique bien informé dirait ?
- Où ma logique est faible ?
- Propose une version plus humble si je survends le pilote.
Priorité : vérité > accord. Français québécois.
```

**Usage :** relire un plan d’affaires ou une slide avant un rendez-vous.

## 3. Pilote municipal 90 j (sur mesure CirculAI)

```text
Tu es rédacteur pour un OBNL québécois (économie circulaire).
Rédige [lettre 1 page / script 60 s / FAQ 5 questions] pour un pilote CirculAI :
- 1 site, 90 jours, 3 preuves vérifiables (flux, matching, confiance partenaire)
- Pas de blockchain, pas de promesse miracle
- Egor69 / Verse = hors dossier institutionnel
- Ville cible : Québec / Limoilou
- Lien kit : https://egor69.ca/docs/circulai-kit-regional
Commence par 2 questions de clarification.
```

## 4. Seconde main — post Facebook (Mon-IA + Webikeo, adapté)

```text
Tu es community manager pour une marketplace locale au Québec (français).
Produit : seconde main — vente, don, échange, réparation près de chez soi.
Équation à mentionner une fois : Style + Économie + Écoresponsabilité = Le Nouveau Chic.
Ton : chaleureux, concret, pas moralisateur.
Longueur : 80–120 mots + 3 hashtags Québec.
CTA : lien vers /seconde-main — inscription gratuite en 60 s.
INTERDIT : faux chiffres d’utilisateurs ou « des milliers de membres ».
```

## 5. Contenu engageant — 10 idées sans exécuter (Webikeo)

```text
Agis comme stratège content pour [CirculAI OU Egor69 — précise lequel].
Public : [citoyens Limoilou / décideurs / lecteurs encyclopédie].
Donne 10 idées de posts (titre + angle + format : carrousel, reel, article court).
Chaque idée = 1 phrase « pourquoi ça sert le quartier » ou « pourquoi c’est honnête ».
Pas de texte complet — seulement la liste numérotée.
```

## 6. Raisonnement structuré — expliquer ΔM (BDM)

```text
Explique l’équation ΔM = M_entrée − M_sortie − M_stock pour un citoyen de Québec.
Réponds en 3 niveaux :
- Débutant (analogie placard / don / achat d’occasion)
- Intermédiaire (tableau 3 colonnes)
- Expert (limites : ce n’est pas une certification scientifique)
2 questions de clarification d’abord. Pas de jargon blockchain.
```

## 7. Data / pilote — indicateurs honnêtes (Data Bird, adapté)

```text
Tu es analyste pour un pilote territorial modeste (petits volumes).
Je te donne des chiffres bruts : [coller tableau ou liste].
Tâches :
1. Résumer en 3 bullets pour un élu (sans embellir)
2. Signaler les données manquantes ou douteuses
3. Proposer 3 KPI simples pour les 90 prochains jours
Ne extrapole pas de tendance si n < 10 événements.
```

## 8. Planche encyclopédie — texte Larousse (sur mesure Egor69)

```text
Tu rédiges la légende d’une planche d’encyclopédie or & noir (style Larousse illustré).
Titre planche : [TITRE]
Mots-clés : [3 mots]
Contraintes : 120–180 mots corps + 1 citation courte en italique (légende dorée).
Ton : poétique mais ancré — CirculAI terrain, Egor69 rêve, lecteur = héros.
Pas de liste à puces. Pas de « Résonances » en annexe — tout dans le texte.
```

## 10. Couches philo vs public (ton Codex)

```text
Aide-moi à séparer ce qui va en PUBLIC ce soir vs PRIVÉ (carnets).
PUBLIC autorisé : 1 speech, kit CirculAI, 3 preuves, page /seconde-main.
PRIVÉ : grimoire entier, clown, joual, codes — matière première seulement.
Résultat : tableau 2 colonnes + 1 phrase « ce qu’on dit au maire ».
```
