# Partenaires à approcher — ils font le terrain, vous codez la vision

**Rôle du fondateur (Dominic) :** architecture, développement, vision produit CirculAI — **pas** prospection froide quotidienne, **pas** gestion municipale complète.

**Rôle des partenaires :** introduction, animation locale, preuves, financements, légal — selon colonne ci-dessous.

---

## Légende des rôles

| Code | Signification |
|------|----------------|
| **INTRO** | Introduit au cabinet / OBNL / commerce |
| **TERRAIN** | Anime le site pilote, utilisateurs réels |
| **PREUVES** | Signe témoignage, valide chiffres |
| **FIN** | Subventions, sponsors, budget pilote |
| **COMM** | Presse locale, radio, événements |
| **JUR** | Contrats, incorporation, conformité |

---

## Priorité 1 — Sans eux, le pilote Québec ne décolle pas

| Organisation / type | Pourquoi | Rôles | Premier geste |
|---------------------|----------|-------|---------------|
| **OBNL référent** (repair café, éco-quartier, maison jeunesse) | Hôte du site pilote | TERRAIN · PREUVES · INTRO | Café 30 min + démo tablette |
| **Bibliothèque municipale / BANQ locale** | Inclusion numérique + atelier | TERRAIN · INTRO | Atelier « hub circulaire » 1 h |
| **Centres communautaires / MJC** | Volume citoyen | TERRAIN · COMM | Affiche QR `/pilote` |
| **Conseil régional de l’environnement — Capitale-Nationale** | Crédibilité écologique | INTRO · PREUVES | Demande liste projets circulaires |
| **RECYC-QUÉBEC** (programmes, pas « partenariat ») | Alignement politique publique | FIN · PREUVES | Veille appels de projets 2024–2028 |

## Priorité 2 — Municipal (après OBNL)

| Cible | Pourquoi | Rôles | Premier geste |
|-------|----------|-------|---------------|
| **Cabinet — vie communautaire / culture** | Aligné maire (parcours communautaire) | INTRO | Lettre + kit PDF |
| **Cabinet — développement économique** | PME, repair, ESS | INTRO · FIN | Dossier pilote 90 j |
| **Cabinet — environnement** | Circularité, parcs | INTRO · PREUVES | Scénario A Nature QC |
| **Arrondissement pilote** (Limoilou, Saint-Roch, etc.) | Un seul site | TERRAIN | Quartier + 1 parc |
| **Ville de Québec — bibliothèques** | Déploiement sans passer par le maire jour 1 | TERRAIN | Pilote bibliothèque |

*Ne pas confondre « alignement thématique » avec endossement du maire.*
