# Vous êtes le héros de cette encyclopédie

**Planche :** `1A` — Porte de l'Oméga Vert

---

## Comment lire cet atlas

Ce livre n'est pas seulement à **consulter** : il est à **habiter**. À chaque seuil, vous choisissez un **rôle** — pas à vie, pour un **parcours**.

| Choix | Rôle | Commencez au |
|-------|------|--------------|
| **A** | Décideur · OBNL · territoire | **Tome I — Territoire** |
| **B** | Bâtisseur · code · preuves | **Tome 0 — Fondations**, puis Tome I |
| **C** | Explorateur · sens · Verse | **Tome 0**, ch. 4, puis **Tome IV** |
| **D** | Archiviste · transmission | **Tome 0**, ch. 6, puis **Annexe Atlas** (planches) |

> **Encadré**  
> Le **Guide du héros** (fin du volume) donne les **numéros de page** exacts après assemblage. Les choix A–D ne se ferment pas : vous pouvez changer de tome entre deux sessions.

---

## Votre serment (optionnel)

Avant de tourner la page, vous pouvez vous dire :

1. Je ne confonds pas **symbole** et **preuve**.  
2. Je ne publie pas de chiffre que je n'ai pas **mesuré**.  
3. Je laisse une **trace** utile à quelqu'un d'autre.
