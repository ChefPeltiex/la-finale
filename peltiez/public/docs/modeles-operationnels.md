# Modèles de travail à calibrer

> **Note** : ces formules sont des **modèles opérationnels** pour structurer le travail sur la plateforme — pas des lois physiques ni des affirmations scientifiques. Chaque coefficient doit être calibré sur des données réelles.

## 1. Circulation des biens

`Impact_local = (objets_réutilisés × facteur_CO₂_objet) / population_zone`

## 2. Confiance du réseau

`Confiance = (transactions_validées + avis_vérifiés) / (signalements + 1)`

## 3. Engagement explorateur

`Curiosité = pages_atlas_ouvertes × profondeur_parcours / temps_session`

## 4. Souveraineté des données

`Souveraineté = données_hébergées_conformes / données_totales_utilisateur`

## 5. Régénération communautaire

`Régénération = (dons + réparations) / (ventes_neuves_proxy + 1)`

## 6. Équilibre multivers (navigation)

`Équilibre_pôle = visites_pôle / Σ(visites_tous_pôles)`
