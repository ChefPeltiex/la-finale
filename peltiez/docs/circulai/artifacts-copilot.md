## Mise à jour : comment synchroniser

1. Ouvrir l’artifact Copilot → exporter ou copier le texte final.  
2. Coller dans `content-reservoir/inbox/` (workflow reservoir) **ou** proposer une PR sur le `.md` cible.  
3. Vérifier chiffres : **Statistique Québec**, **RECYC-QUÉBEC** — pas de stats inventées.  
4. Publier : les fichiers dans `public/docs/circulai/` sont servis sur le site.
