## 6.1 — Pourquoi un livre alors qu'une app

Les applications municipales et les marketplaces locales **meurent souvent** faute de masse critique. Les **livres**, les **archives**, les **univers documentés** survivent autrement : par la **lenteur**, la **beauté**, la **transmission familiale**.

Ce Volume 0 n'est pas un renoncement à CirculAI. C'est la **couche qui voyage** quand le serveur change, quand le maire tourne, quand le fondateur dort.

| Support | Vitesse | Durée probable |
|---------|---------|----------------|
| Pilote 90 j | Rapide | Preuve locale |
| Plateforme | Moyenne | Outil vivant |
| Encyclopédie / livre | Lente | Mémoire culturelle |

## 6.2 — Ce que je transmets (et ce que je ne transmets pas)

### Transmis

- une **méthode** : deux mondes, une éthique, trois preuves ;
- une **question** : comment relier circularité et sens sans mentir ;
- un **atlas** : planches, textes, routes nommées ;
- le droit pour chacun de **briller à sa façon** (technique, artiste, animateur OBNL).

### Non transmis comme vérité

- un empire garanti ;
- une révolution mondiale immédiate ;
- des chiffres non mesurés ;
- la prétention de remplacer les institutions sans elles.

## 6.3 — Volume 1 (teaser)

**Volume 1 — Territoire** (à écrire) pourrait contenir :

- encyclopédie du **Québec** (villes, parcs, repair cafés) ;
- fiches **Nature** alignées sur des lieux réels ;
- carnets de pilote **anonymisés** ;
- planches Codex **complètes** (12 sections × 3).

Le Volume 0 est la **fondation**. Le Volume 1 est le **atlas élargi**.

## 6.4 — Pour un éditeur

Genre proposé : essai hybride · fiction documentaire · atlas personnel.  
Public : culture, ESS, écologie, humanités numériques, Québec francophone.  
Longueur cible Volume 0 : ~100 pages équivalent + planches.

> *« Volume 0 d'une encyclopédie hybride : moitié outil territorial (CirculAI), moitié univers d'exploration (Egor69) — explicitement séparées. »*

---

## 6.5 — Pour les générations suivantes

Si tu lis ceci dans vingt ans :

- cherche d'abord si un **pilote** a eu lieu (preuves, dates, noms consentis) ;
- distingue ce qui était **code** de ce qui était **rêve** ;
- continue la boucle : **réparer, partager, documenter** — pas idolâtrer un PDF.
