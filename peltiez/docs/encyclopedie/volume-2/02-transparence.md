## 2.1 — Cœur pur (symbolique)

**Cœur pur** = intentions **lisibles** par un tiers :

- pas de métrique cachée ;
- pas de dark pattern ;
- pas de faux avis.

Ce n'est pas la pureté morale absolue — c'est la **lisibilité**.
