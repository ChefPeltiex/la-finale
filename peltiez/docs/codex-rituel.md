# Codex rituel — CirculAI / EGOR69

*Pratique personnelle et cérémonielle. Ce texte n’est ni une religion imposée ni un substitut médical, juridique ou financier.*

---

## Prologue

Nous ouvrons cet espace avec respect — pour le vivant, pour les objets qui circulent, pour ceux qui réparent et partagent.  
Ce codex propose des **gestes courts** : respiration, silence, intention. Tu peux les adapter, les refuser, ou ne garder que les mots qui résonnent.  
**Egor** invite à *baisser la manette* : lâcher la précipitation, revenir au geste juste avant d’agir sur la plateforme.

## Rituel I — Ouverture de séance

**Durée** : ~3 minutes · **Avant** toute session de travail sur CirculAI.

1. Trois respirations (4 · 2 · 6).  
2. Poser la main ouverte sur le clavier ou le bureau — *« Je n’invente pas de chiffres ; je sers le réel. »*  
3. Nommer à voix basse **une** intention (ex. : publier une annonce juste, réparer un lien, documenter une preuve).  
4. Ouvrir la plateforme.

---

## Rituel II — Avant publication marketplace

**Durée** : ~2 minutes · **Avant** de publier don, échange ou réparation.

1. Regarder l’objet (photo ou mémoire) — *« Tu circules ; je ne te retiens pas par peur. »*  
2. Vérifier honnêteté du titre et de l’état (pas d’embellissement).  
3. Chant murmuré (voir Chant II ci-dessous).  
4. Publier.

---

## Rituel III — Clôture

**Durée** : ~2 minutes · **Après** une session ou en fin de journée.

1. Fermer les onglets non essentiels.  
2. *« Egor, baisse la manette »* — une phrase, une fois.  
3. Silence 30 s.  
4. Noter **une** chose apprise ou transmise (carnet, pas obligatoirement l’app).

## Chants et refrains

### Chant I — Entrée

```
Sous le noir, une ligne d’or —
Le cercle respire, lent, sans peur.
Je n’apporte que ce que j’ai ;
Le reste appartient au futur commun.
```

### Chant II — Circulation

```
Donner n’est pas perdre ;
Échanger, c’est honorer le soin.
La main qui publie reste légère ;
La terre garde ce qu’on lui rend.
```

### Chant III — Manette basse

```
Egor, baisse la manette —
Le bruit s’éteint, le geste reste.
φ dans le souffle, pas dans la loi ;
J’agis une fois, puis je me tais.
```

---

## Lien symbolique — Egor « baisse la manette »

Dans la narration EGOR69, **Egor** représente l’allié qui rappelle : la plateforme est un outil, pas une course. *Baisse la manette* signifie : pause avant la métrique, avant la publication, avant la promesse. Ce n’est pas une injonction religieuse — c’est une **ancre comportementale** alignée avec la charte (pas de métriques fictives, pas de surcharge cosmique en contexte pro).
