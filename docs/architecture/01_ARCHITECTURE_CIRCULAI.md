## Positionnement public

CirculAI est une cellule IA locale souveraine appliquée à l’économie circulaire :
un système qui transforme un ordinateur, un repo et une démo publique en organisme numérique capable d’organiser, documenter, coder, sauvegarder et faire évoluer un projet sous contrôle humain.

## Positionnement institutionnel

CirculAI doit être présenté comme :

- une initiative citoyenne en développement ;
- un prototype démontrable ;
- un pilote possible sur 90 jours ;
- un outil de coordination locale ;
- une méthode de preuve honnête ;
- une plateforme francophone d’économie circulaire.

## Positionnement culturel

Egor69 n’est pas un service municipal.

Egor69 est :

- un univers narratif ;
- un bréviaire ;
- une encyclopédie ;
- une couche symbolique ;
- une mémoire culturelle ;
- un espace d’exploration.
